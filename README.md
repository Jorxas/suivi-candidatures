# Suivi de candidatures

Interface publiee sur https://jorxas.github.io/suivi-candidatures/.

La connexion utilise le service prive du proprietaire. Les statuts et documents sont conserves dans ce service, pas dans ce depot public. Les nouvelles entreprises sont chargees depuis l'API sans republier cette interface.

Fonctions : suivi des envois, recherche et filtres, conservation des anciens dossiers, telechargement des PDF, texte d'e-mail, partage mobile quand disponible, brouillon `.eml` avec les pieces preparees. La page ne transmet aucun e-mail automatiquement.
